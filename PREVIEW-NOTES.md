# Свои — предварительная Windows-сборка

Скачайте **Svoi-1.1.0.exe** и запустите двойным щелчком. Распаковывать папки и вводить адрес сервера не нужно. Все необходимые файлы включены в один переносимый EXE. Подходит для Windows 10/11 x64.

**Общий онлайн-сервис ещё не подключён. Переписка и звонки с друзьями пока недоступны.** Приложение открывается и сообщает об этом. После подключения сервиса к конфигурации приложение сможет найти его автоматически; повторно скачивать клиент не потребуется.

Это предварительная сборка, а не готовый онлайн-релиз. Инструкции по бесплатному размещению с лимитами: **CLOUD-README.md** в исходниках. Релиз с подключённым сервисом публикуется отдельно после проверки его доступности.

EXE собран и запущен на Windows в GitHub Actions. Проверены окно подключения, автоматическое обнаружение конфигурации и отсутствие поля адреса сервера. Цифровой подписи издателя у приложения пока нет. Рядом с файлами опубликованы SHA-256.
