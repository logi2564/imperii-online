# Zone Motion — проект переноса на Windows

Ветка `zone-motion-pc` содержит восстановленный Unity-проект Zone Motion 1.275 с управлением для ПК. **Готовый EXE пока не собран**. Для сборки и запуска двойным щелчком добавлен `ИГРАТЬ.cmd`; сначала нужен установленный и активированный Unity 2017.2.0f3. Инструкция — [zone-motion-pc/README-PC.md](zone-motion-pc/README-PC.md). Меню и 13 локаций восстановлены, игровые скрипты прошли статическую компиляцию. Запуск и игровой процесс на Windows ещё нужно проверить.

## Империи: Война за мир — альфа 0.2

В этом репозитории также находится **«Свои» — чат и голос для друзей с клиентом для Windows**. Инструкции запуска сервера и настольного приложения: [CHAT-README.md](CHAT-README.md). Исходная игра ниже работает отдельно; сервер чата запускается командой `npm start`.

Версия 1.1 подключается к общему сервису автоматически. Для бесплатного размещения с лимитами подготовлена [конфигурация Cloudflare Workers](CLOUD-README.md); хостинг ещё требует подключения аккаунта владельца.

Бесплатный статический браузерный прототип стратегии. Открывается на ПК и телефонах.

## Публикация

Репозиторий настроен для GitHub Pages через GitHub Actions:
- сайт состоит из `index.html` и не требует сборки;
- workflow находится в `.github/workflows/pages.yml`;
- при каждом push в `main` GitHub Actions пытается опубликовать сайт.

Публичный адрес после успешной публикации:
https://logi2564.github.io/imperii-online/

Если адрес пока показывает 404, открой вкладку **Actions** в репозитории и дождись успешного завершения workflow **Publish Imperii to GitHub Pages**. Если workflow сообщает, что Pages не включён, открой **Settings → Pages** и в **Build and deployment → Source** выбери **GitHub Actions**.

## Что есть в прототипе

- карта из 48 провинций;
- выбор земель, строительство и улучшение баз;
- найм отрядов, технологии и атаки соседних провинций;
- золото, древесина, камень, провизия и железо;
- опыт и уровни империи;
- простая анимация отрядов и эффектов сражений;
- интерфейс адаптируется к мобильным экранам;
- попытка P2P-подключения друзей по коду мира через PeerJS.

## Важно о мультиплеере

Это экспериментальная P2P-альфа, не постоянный сервер. Создатель мира должен держать вкладку игры открытой, иначе комната перестанет работать. Соединения могут не устанавливаться в некоторых сетях/браузерах. Мир не имеет постоянного серверного сохранения и может исчезнуть после закрытия вкладки хоста. Не вводите личные или секретные данные в игре.
