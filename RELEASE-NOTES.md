# Свои 1.0.0

Первая версия чата и голоса для небольшой компании друзей.

- Текстовые и голосовые каналы, приглашения по ссылке.
- Сообщения в реальном времени, история, реакции и поиск в загруженных сообщениях.
- Участники в сети, индикатор набора, управление микрофоном и звуком.
- Настольный клиент для Windows 10/11 x64.

## Скачать и запустить

Скачайте **Svoi-1.0.0-win32-x64.zip**, распакуйте **всю папку**, затем запустите **Svoi.exe**. Вставьте HTTPS-ссылку приглашения от владельца сервера. Смена сервера — **Ctrl + Shift + S**.

Приложение распространяется в переносимом архиве без установщика и цифровой подписи.

## Общий сервер

Всем участникам нужен один работающий сервер. Для его запуска скачайте **Svoi-source.zip** и прочитайте **CHAT-README.md**. В архив входят сервер, исходники клиента, `START-SERVER.cmd` для локального запуска и конфигурация Render с постоянным диском. Размещение на Render требует вашего аккаунта и платного тарифа; оно не выполняется при скачивании приложения.

Для микрофона через интернет нужен HTTPS. Некоторые сети дополнительно требуют TURN-сервер. Голос локально проверен в двух окнах Electron с тестовыми микрофонами и получением аудиопакетов; звонок между вашими сетями нужно проверить после размещения сервера.

Рядом с архивами находятся файлы SHA-256 для проверки целостности.
