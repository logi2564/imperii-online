# Свои 1.1.0

Обновление автоматического подключения к общему онлайн-сервису.

- Убран экран ввода адреса сервера и пункт «Сменить сервер».
- Приложение находит сервис автоматически и проверяет его доступность.
- Добавлены повторное подключение, кеш проверенного адреса и честное сообщение, если онлайн-сервис ещё не запущен.
- Подготовлен бэкенд для бесплатного Cloudflare Workers с постоянной SQLite-базой и Hibernation WebSockets.

- Текстовые и голосовые каналы, приглашения по ссылке.
- Сообщения в реальном времени, история, реакции и поиск в загруженных сообщениях.
- Участники в сети, индикатор набора, управление микрофоном и звуком.
- Настольный клиент для Windows 10/11 x64.

## Скачать и запустить

Скачайте **Svoi-1.1.0.exe** и запустите двойным щелчком. Распаковка папок не требуется. Приложение подключается само. При первом входе выберите имя и используйте приглашение от друга. Повторить подключение — **Ctrl + Shift + R**. ZIP с переносимой папкой также доступен.

Приложение распространяется без установщика и цифровой подписи издателя.

## Общий сервер

Общий сервис запускается независимо от ПК участников. Инструкции для администратора: **CLOUD-README.md**. Онлайн-релиз публикуется только после проверки размещённого сервиса. Пока размещение не завершено, доступна отдельно обозначенная предварительная EXE-сборка с сообщением об отсутствии сервиса. Бесплатный Cloudflare Workers имеет лимиты; при превышении квот сервис может быть недоступен до их сброса. Платный тариф не подключается автоматически.

Для микрофона через интернет нужен HTTPS. Некоторые сети дополнительно требуют TURN-сервер. Голос локально проверен в двух окнах Electron с тестовыми микрофонами и получением аудиопакетов; звонок между вашими сетями нужно проверить после размещения сервера.

Рядом с архивами находятся файлы SHA-256 для проверки целостности.
