ЕВРОПЕЙСКАЯ ВОЙНА 4 — НАПОЛЕОН · 0.3.0

ПОЛНОЦЕННЫЕ АВТОНОМНЫЕ СБОРКИ ДЛЯ WINDOWS И ANDROID
В обеих сборках есть движок и файлы игры: шесть глав кампаний, завоевание,
обучение, штаб, генералы, предметы, сохранения и сетевое подключение.
Одиночная игра на телефоне работает без компьютера и без интернета.
При запуске открывается главное меню. Сохранение загружается по выбору игрока.

WINDOWS 10/11 X64
1. Распакуй ВЕСЬ архив в папку.
2. Запусти EuropeanWar4-Napoleon.exe.
3. Выбери «Кампания», «Завоевание», «Обучение» или «Штаб».
4. Загрузка сохранений доступна через кнопку загрузки в меню выбранного режима.
Не запускай EXE прямо из ZIP: рядом нужны библиотеки и папка server.
Unity, эмулятор и отдельный .NET устанавливать не нужно.

ANDROID 8 И НОВЕЕ
1. Установи EuropeanWar4-Full-Android.apk.
2. Открой «Европейская война 4» — появится главное меню.
3. Кампании, завоевание и сохранения работают офлайн.
Это самостоятельное приложение с другим идентификатором, чем прежний
клиент «European War 4 Online». Оно устанавливается рядом с ним.
Сохранения между приложениями автоматически не переносятся.

МУЛЬТИПЛЕЕР ВНУТРИ ИГРЫ
На ПК: «Мультиплеер» → «Создать партию» → выбери карту и страну → создай.
Скопируй код EW4-… и отправь другу.
На телефоне: «Мультиплеер» → вставь код → «Подключиться» → выбери страну.
После выбора страны другом создатель нажимает «Начать игру».
У каждого своя страна, за остальные играет компьютер.
ПК создателя нужен только для сетевой партии; держи его и игру включёнными.
Используется бесплатное соединение Cloudflare Quick Tunnel; при следующем
запуске создателя нужен свежий код. Сохранённая сетевая партия остаётся на ПК.

ЯЗЫК
Русские игровые строки, диалоги, описания миссий, меню и названия городов
встроены в обе сборки. Тексты кампаний и часть имён переведены автоматически;
основные команды интерфейса проверены отдельно. Фоновые исторические рисунки
могут содержать исходные картографические надписи.

РИСОВАНИЕ И ЗАПУСК
В Windows аппаратное ускорение и WebGL отключены. Карта рисуется через
Canvas 2D, анимация ограничена 30 кадрами, разрешение поверхности ограничено.
Используется компактный шрифт с кириллицей вместо китайских шрифтов.
Сохранённая партия не восстанавливается до явного выбора игрока.
Это снижает нагрузку, но не устанавливает причину прежнего синего экрана.
Для чтения STOP CODE и версии видеодрайвера есть Check-Windows.cmd.
Он только читает несколько полей журнала и сохраняет Windows-diagnostic.txt
в папке игры; ничего не отправляет и не собирает дампы памяти.

СОХРАНЕНИЯ
Windows: %LOCALAPPDATA%\BroEW4Online\saves\single — одиночная игра;
%LOCALAPPDATA%\BroEW4Online\saves — сетевая партия и старые файлы.
Android: внутренние данные «Европейская война 4»; удаление приложения удаляет
эти данные. APK подписан ключом сборки, а не сертификатом Google Play.
