Как играть

Создатель выбирает карту и страну, отправляет приглашение другу и ждёт выбора второй страны. Затем нажимает «Начать партию». Ходите по очереди: выберите свой отряд на карте, затем клетку для перемещения или вражеский отряд для атаки. Кнопка «Завершить ход» передаёт управление дальше.

Для игры друг против друга выбирайте страны противоборствующих коалиций; для совместной игры — союзные страны. Действуют дипломатия и условия победы выбранной карты. В завоевании итог считается для каждой страны отдельно.

На телефоне удобнее играть горизонтально. Карту можно двигать и масштабировать. Партия сохраняется после действий. При обрыве связи открой ту же ссылку снова. Во время игры ПК создателя и окно запуска должны оставаться включёнными.
