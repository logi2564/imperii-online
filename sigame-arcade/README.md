# БРО · АРКАДА

61 мини-игра с разными правилами, управлением мышью/касаниями и личным ответом после победы. 60 обычных вопросов СИГейма и отдельный финальный рейд со ставкой для всех.

Приложение: <https://logi2564.github.io/imperii-online/mini-games/>.

`Bro-Arcade-61.siq` содержит HTML-игры. `Bro-Arcade-61-QR.siq` использует большие QR-карточки и подходит клиентам без интерактивного HTML. Подробные настройки ведущего и ограничения — в [HOW-TO-PLAY.txt](HOW-TO-PLAY.txt).

Время игры — 90–300 секунд. Сцена вопроса получает время игры + 45 секунд; в HTML-паке перед ней есть пятисекундная карточка. Ведущему нужно разрешить ответы во время вопроса (фальстарты), чтобы победитель мог отвечать сразу.

Игры написаны без внешних JS-библиотек. Встроенный HTML и отдельные HTML-файлы из офлайн-архива не требуют сетевых ресурсов. QR-варианту нужен доступ к опубликованному сайту. Ответы показываются локально после победы; защиты от исследования исходного кода нет.

## Сборка

Нужны Python 3.12, Node.js, .NET 8 и Chromium/Chrome:

```sh
pip install qrcode==8.2 pillow==11.3.0 playwright==1.55.0 zxing-cpp==2.3.0
python sigame-arcade/tools/build.py --prepare
python -m http.server 8794 --bind 127.0.0.1 --directory mini-games
# Во втором терминале, при необходимости задав BROWSER_EXECUTABLE:
python sigame-arcade/tests/smoke.py
python sigame-arcade/tests/playthrough.py
python sigame-arcade/tools/render_cards.py
python sigame-arcade/tests/qrcodes.py
python sigame-arcade/tools/build.py
python sigame-arcade/tools/validate.py
dotnet run --project sigame-arcade/tools/OfficialLoader -- .
python sigame-arcade/tests/embedded.py
```

`playthrough.py` проходит все 61 игры через обработчики ввода, не изменяя игровое состояние и не вызывая победу напрямую. `smoke.py` проверяет ПК, ширину телефона 360 px, условия таймера, повторы и отсутствие ответа при проигрыше/тайм-ауте. `embedded.py` открывает все HTML-файлы непосредственно из собранного SIQ без внешних ресурсов и проверяет область клиента 800×500 и телефон.

Официальная SIPackages 7.14.0 проверяет загрузку обоих пакетов, наличие 61 вопроса, содержимое HTML/картинок, ответы, длительности и финальный `stakeAll`.

Графика — программная Canvas/CSS. QR-коды создаются qrcode; браузерная проверка и изображения карточек — Playwright. Игра в настоящем Windows-клиенте СИГейма и на физическом телефоне не проверялась: проверены официальный загрузчик пакетов и Chromium с эмуляцией касаний.

При проверке встроенного HTML по умолчанию используется локальный HTTP без внешних зависимостей. `ARCADE_TEST_FILE_URLS=1` дополнительно пробует file://; в управляемом Chromium этот протокол может блокироваться политикой браузера.
