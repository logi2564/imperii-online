# БРО · БЛИЦ

61 мини-игра внутри вопросов SI Online. Каждый игрок проходит у себя; слово появляется после победы. QR-карточки и переходы на отдельный сайт убраны.

Обычная игра занимает 15–35 секунд, финал 40. Перед каждой игрой идёт автоматическая подготовка 5 секунд. Сумма всех максимальных окон, включая трёхсекундный запас на ответ, — 34:08; ответы и паузы ведущего добавляются отдельно.

Переработаны сами задания, а не только таймеры: сокращены аркадные цели и повторы памяти, ускорена экономика коротких стратегий, добавлено управление пальцем в парковке/стыковке и шаги по касанию в лабиринтах. Сапёр заменён на логическую задачу 4×4 без случайных угадываний, сейф — на трёхцветный код. В каждый HTML включается только одна механика: менее 30 КБ без сетевых зависимостей.

Пак: `Bro-Arcade-Blitz-61.siq`. Настройка комнаты — [HOW-TO-PLAY.txt](HOW-TO-PLAY.txt). Ведущему нужно включить фальстарты. Файл не обновляет клиент: требуется версия SI Online с HTML-контентом.

## Проверки

- `playthrough.py` проходит 61 игру через ввод. Касание расходует 180 мс виртуального времени; шаги лабиринта тоже не мгновенные. Сапёр выводит ходы только из видимых чисел, кодовый сейф решается по обратной связи.
- `embedded.py` открывает HTML из SIQ через **неизменённый React-компонент SI Online HtmlContent.tsx** в его sandbox iframe. 61 игра × 4 размера, включая телефон; проверяются автозапуск, геометрия, касания, команды паузы/ответа, течение времени при редких кадрах, отсутствие внешних запросов и раздельные ответы двух игроков. Источник и MIT-лицензия — в `tests/sionline/`.
- `validate.py` и официальная `SIPackages 7.14.0` проверяют реальный SIQ: 61 HTML-вопрос, длительности, ответы и один финальный `stakeAll`.

Интеграционный стенд использует настоящий HTML-компонент, но тестовые Redux/server actions. Полноценная удалённая партия, физический Android и Windows-клиент здесь не проверены. Сам SIQ не может менять сетевую синхронизацию SI Online или защитить клиентский ответ от чтения исходников.

## Сборка

Нужны Python 3.12 + Playwright, Node.js + React 17/esbuild для стенда, Chromium и .NET 8:

```sh
python -m pip install playwright==1.55.0
npm install --prefix /tmp/si-blitz-tools --no-audit --no-fund react@17.0.2 react-dom@17.0.2 esbuild@0.25.0
export NODE_PATH=/tmp/si-blitz-tools/node_modules
export ARCADE_REACT_MODULES=$NODE_PATH
python sigame-arcade/tools/build.py --prepare
python sigame-arcade/tools/build.py
python sigame-arcade/tools/validate.py
dotnet run --project sigame-arcade/tools/OfficialLoader -- .
# Для playthrough.py нужен локальный сервер предпросмотра на 8794:
python -m http.server 8794 --bind 127.0.0.1 --directory mini-games
# В другом терминале:
python sigame-arcade/tests/playthrough.py
python sigame-arcade/tests/embedded.py
```

При необходимости задайте `BROWSER_EXECUTABLE` на установленный Chromium/Chrome. Локальный предпросмотр используется только при разработке; игрокам он не нужен.
