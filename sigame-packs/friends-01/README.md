# БРО-ПАК №1 — Игры и аниме

Готовый пакет вопросов для SIGame: один раунд, шесть тем по пять вопросов, цены 100–500. Русский язык, короткие ответы, русские и английские варианты названий. WoW, Warcraft III и Terraria включены по просьбе пользователя.

| Тема | Вопросов | Формат |
| --- | ---: | --- |
| Игры по скриншоту | 5 | Игровые скриншоты |
| Игры на слух | 5 | Звуки; один вопрос со знаменитой записью игрока WoW |
| Игры по музыке | 5 | Фрагменты саундтреков около 14 секунд |
| Аниме по кадру | 5 | Кадры из оригинальных опенингов без названия сериала |
| Аниме по опенингу | 5 | Аудиофрагменты около 14 секунд |
| Ответ в пару слов | 5 | Обычные вопросы о Warcraft и Terraria |

Все 10 изображений и 15 MP3 встроены в `.siq`. Для вопросов не используются внешние ссылки. Достаточно назвать игру или аниме; угадывать песню, исполнителя и сезон не требуется. Источники и комментарии ведущего находятся в метаданных вопросов и показываются после ответа.

Выберите `Bro-Pack-01.siq` внутри SIGame при создании игры. Не распаковывайте файл. Полная краткая инструкция — [HOW-TO-PLAY.txt](HOW-TO-PLAY.txt). Для игры с друзьями через интернет нужен сам SIGame с его сетевым подключением; встроенные медиа от внешних сайтов не зависят.

## Сборка и проверка

Из корня репозитория:

```bash
python sigame-packs/tools/build_pack.py --pack sigame-packs/friends-01
python sigame-packs/tools/validate_pack.py dist/sigame-pack/Bro-Pack-01.siq --pack sigame-packs/friends-01
dotnet run --project sigame-packs/tools/OfficialLoader --configuration Release -- dist/sigame-pack/Bro-Pack-01.siq dist/sigame-pack/build-info.json
```

Для проверки нужны Python 3.12, Pillow, lxml, FFmpeg и .NET SDK 8; игрокам эти инструменты не нужны. [GitHub Actions](../../.github/workflows/sigame-pack.yml) создаёт релиз после успешного импорта и проверки медиа. ZIP воспроизводим: порядок файлов и даты фиксированы, каждое медиа проверяется по SHA-256.

Пак записан в SIQ 4 для совместимости. Локально проверены:

- официальная XML-схема `ygpackage3.1.xsd`;
- импорт библиотекой SIPackages 7.5.6;
- импорт библиотекой SIPackages 7.14.0 с обновлением структуры до SIQ 5, сохранением всех 30 вопросов и доступностью всех 25 медиа;
- полное декодирование MP3, отсутствие тишины и клиппинга, длительность и отсутствие названия ответа в ID3;
- декодирование изображений и ручной просмотр выбранных кадров.

Полная партия через графический клиент SIGame ещё не сыграна.

## Материалы

[pack.json](pack.json) содержит вопросы и ответы, поэтому игрокам его до партии лучше не открывать. [media-sources.json](media-sources.json) содержит URL, исходные и итоговые SHA-256, обработку и авторство каждого фрагмента. Нейтральные имена файлов не выдают ответы. В репозитории сохранены только выбранные кадры и короткие аудиофрагменты; полные видео и саундтреки не включены.

Авторство тем — logi2564; текст вопросов и сборка — Codex. Игры, кадры, музыка и запись голоса принадлежат их авторам и правообладателям; лицензия программных инструментов не переопределяет права на эти материалы. Это неофициальная подборка для игры с друзьями.

XML-схема взята без изменений из VladimirKhil/SI, commit `d5686f485c3bf815a8ca66e1addea1120952e020`, файл `assets/ygpackage3.1.xsd`; SHA-256 `fbb63629c7af14187af4b7eb79466d1472adf3045e34eb25bd270b7e4abce9ac`. Её лицензия MIT сохранена рядом со схемой. Проверяющая библиотека SIPackages — Vladimir Khil, MIT, официальный NuGet.
