# БРО-ПАК — 120 вопросов: Игры и аниме

Расширенный пакет для SIGame: **120 вопросов, четыре раунда по 30**. Каждый раунд содержит шесть тем по пять вопросов. В него входят первые 30 вопросов и ещё 90 новых; пакет полностью заменяет первоначальный небольшой выпуск.

| Тип вопросов | Всего | Медиа |
| --- | ---: | --- |
| Игры по скриншоту | 20 | 20 разных игровых скриншотов |
| Голоса, звуки и эффекты игр | 20 | 20 разных аудиофрагментов |
| Музыка игр, городов и локаций | 20 | 20 разных музыкальных фрагментов |
| Аниме по кадру | 20 | 20 кадров из оригинальных опенингов |
| Аниме по опенингу | 20 | 20 разных аудиофрагментов |
| Ответ в пару слов | 20 | Обычные вопросы о Warcraft, WoW и Terraria |

Стоимость вопросов по раундам: 100–500, 200–1000, 300–1500, 400–2000. Все вопросы обычные, без ставок и котов в мешке; дополнительный финал не требуется. Весь пак — один файл `Bro-Pack-120.siq`, примерно 18 МБ. Выберите его внутри SIGame при создании игры; распаковывать не нужно. [Инструкция](HOW-TO-PLAY.txt).

По просьбе пользователя сделан дополнительный акцент на WoW, Warcraft III и Terraria: есть голоса юнитов, музыка столиц и локаций, вопросы о персонажах, боссах и событиях. Формулировка объясняет, надо назвать игру, персонажа, место или действие. Для аниме достаточно названия сериала; сезоны, песня и исполнитель не нужны. Голоса юнитов сохранены на языке оригинальной записи; в вопросах есть русские и английские варианты коротких ответов.

Все **40 изображений и 60 MP3 встроены**. Каждый из 100 медиафайлов используется один раз; повторяющиеся файлы и сценарии проверка отклоняет. Для вопросов не загружаются внешние ссылки. Для совместной сетевой игры нужен SIGame с подключением к его серверу.

## Проверка и сборка

Из корня репозитория:

```bash
python sigame-packs/tools/build_pack.py --pack sigame-packs/friends-120
python sigame-packs/tools/validate_pack.py dist/sigame-pack/Bro-Pack-120.siq --pack sigame-packs/friends-120
dotnet run --project sigame-packs/tools/OfficialLoader --configuration Release -- dist/sigame-pack/Bro-Pack-120.siq dist/sigame-pack/build-info.json
```

Для проверки нужны Python 3.12, Pillow, lxml, FFmpeg и .NET SDK 8; игрокам эти инструменты не нужны. [Workflow](../../.github/workflows/sigame-pack.yml) публикует готовый `.siq`, контрольную сумму и отчёты только после проверки всех вопросов, декодирования всех медиа и импорта официальной библиотекой SIPackages 7.14.0.

Формат SIQ 4 обеспечивает совместимость; современная библиотека при чтении переводит структуру в SIQ 5. Проверяются четыре раунда, 24 темы, ровно 120 вопросов, цены, короткие ответы, все ссылки на встроенные файлы, SHA-256, отсутствие пустых изображений, тишины, клиппинга и названий ответов в ID3. Кадры просмотрены вручную; изображения с титульными заставками или названием ответа заменены игровыми кадрами. Полная партия через графический клиент SIGame ещё не сыграна.

## Источники

[pack.json](pack.json) содержит вопросы и ответы. [media-sources.json](media-sources.json) содержит источник, исходный и итоговый SHA-256, параметры подготовки и авторство каждого фрагмента. Не открывайте эти файлы до партии, если хотите отвечать сами.

Скриншоты взяты со страниц игр в Steam и из указанных публичных архивов. Кадры аниме и опенинги подготовлены из оригинальных заставок, доступных в AnimeThemes. Короткие голоса дополнительно взяты из опубликованных паков OpenPeon; их авторы и исходные манифесты указаны в источниках соответствующих фрагментов. Полные видео и саундтреки не включены.

Подбор тем — logi2564; вопросы и сборка — Codex. Игры, кадры, музыка и голоса принадлежат их авторам и правообладателям. Лицензия инструментов или пользовательского звукового пака не переопределяет права на исходную игру или запись. Это неофициальный пак для друзей.
