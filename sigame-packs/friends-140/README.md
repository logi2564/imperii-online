# БРО-ПАК — УЛЬТРАХАРД: 140 вопросов

Сложная редакция прошлого пака: **все 120 вопросов переработаны**, сверху добавлены **20 «Персонаживотных»**. Четыре раунда по 35 вопросов: семь тем по пять в каждом. Один готовый файл `Bro-Pack-140-UltraHard.siq`; [инструкция для игроков](HOW-TO-PLAY.txt).

| Тема | Вопросов | Что изменилось |
| --- | ---: | --- |
| Архивные игры | 20 | Настоящие скриншоты менее известных стратегий и RPG |
| Голоса: точный ответ | 20 | Конкретные расы, герои и юниты Warcraft, StarCraft и Dota 2 |
| Музыка: точный ответ | 20 | Короткие фрагменты: нужны города, темы, авторы, студия или часть игры |
| Редкие аниме: кадры | 20 | Кадры менее массовых сериалов без титульного названия |
| Редкие опенинги | 20 | Семисекундные фрагменты; сериалы сдвинуты относительно темы кадров |
| Лор и механики | 20 | Детали Warcraft и рецепты/предметы Terraria 1.4.4 |
| Персонаживотные | 20 | Новые авторские изображения: животное + герой = склеенное имя |

«Персонаживотные» используют принцип «комар + Артас = Комартас». Ведущий засчитывает авторскую склейку **или обе правильно названные части**. Это позволяет решать визуальную загадку без угадывания единственного написания. Одного имени героя недостаточно. Объяснение каждой пары находится в комментарии соответствующего ответа.

Цены по раундам: 100–500, 200–1000, 300–1500, 400–2000. Все вопросы обычные, без ставок и дополнительного финала. Вопросы уточняют, что назвать: в музыкальной теме одного названия игры часто недостаточно. У аниме не требуются исполнитель и песня. Голоса сохранены на языке записи, предусмотрены русские и английские ответы. Сложность субъективна: фанаты отдельных серий могут знать ответы сразу.

Все **60 изображений и 60 MP3** встроены. Каждый из 120 разных медиафайлов используется ровно один раз. Игровые кадры взяты из официальных галерей Steam; аниме — из оригинальных опенингов AnimeThemes. Картинки персонаживотных сгенерированы отдельно инструментом image_gen; это оригинальные интерпретации, а не кадры из игр. PNG сохранены без редактирования. Полные видео и саундтреки в пакет не включены. Предыдущий опубликованный пак на 120 вопросов сохраняется отдельно.

## Сборка и проверка

Из корня репозитория:

```bash
python sigame-packs/tools/build_pack.py
python sigame-packs/tools/validate_pack.py dist/sigame-pack/Bro-Pack-140-UltraHard.siq
dotnet run --project sigame-packs/tools/OfficialLoader --configuration Release -- dist/sigame-pack/Bro-Pack-140-UltraHard.siq dist/sigame-pack/build-info.json
```

Для сборки нужны Python 3.12, Pillow, lxml, FFmpeg и .NET SDK 8. Игрокам нужен только SIGame и готовый `.siq`. Для сборки старого издания укажите `--pack sigame-packs/friends-120` в командах Python и имя старого файла при импорте.

[Workflow](../../.github/workflows/sigame-pack.yml) публикует скачиваемый файл, контрольную сумму и отчёты после проверки официальной XML-схемы, всех 140 вопросов, 28 тем, цен, ответов, встроенных ссылок, SHA-256, полного декодирования медиа и импорта официальной библиотекой SIPackages 7.14.0. Проверка отклоняет повторяющиеся файлы и сценарии, пустые картинки, тишину, клиппинг и названия ответов в ID3. Кадры просмотрены вручную. Полная партия через графический клиент SIGame ещё не сыграна.

## Источники и спойлеры

[pack.json](pack.json) содержит вопросы и ответы, [media-sources.json](media-sources.json) — происхождение, авторство, исходные и итоговые SHA-256, параметры подготовки. Ссылки на статьи о текстовых ответах также включены в метаданные вопросов внутри SIQ. [generation-prompts.json](generation-prompts.json) сохраняет задания для иллюстраций. Эти файлы раскрывают ответы; игрокам не стоит читать их перед партией.

Подбор тем и идея — logi2564; вопросы, иллюстрации и сборка — Codex. Игры, персонажи, кадры, музыка и голоса принадлежат их авторам и правообладателям. Лицензия пользовательской звуковой подборки не переопределяет права на исходную игру или запись. Это неофициальный пак для друзей.
