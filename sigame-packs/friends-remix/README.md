# БРО-ПАК — РЕМИКС: знакомые игры, аниме и персонаживотные

Обновлённый пакет на **140 вопросов**: четыре раунда по семь тем. Вместо малоизвестных старых стратегий — GTA V, RDR2, Cyberpunk 2077, CS2, Dota 2 и другие массовые игры. Warcraft III и WoW сохранены по просьбе автора; Terraria осталось ровно два вопроса. StarCraft полностью удалён из вопросов и медиа этой редакции.

| Формат | Вопросов |
| --- | ---: |
| Знакомые игры по настоящему скриншоту | 20 |
| Герои, существа и события по игровому звуку | 20 |
| Музыкальные темы и сигналы игр | 10 |
| Боссы и злодеи по уликам | 10 |
| Аниме по кадру | 10 |
| Аниме по семисекундному опенингу | 10 |
| Лор и детали знакомых игр | 20 |
| Персонаживотные | 20 |
| Кривой отзыв — новая авторская тема | 20 |

В аниме входят JoJo, «Магическая битва», «Человек-бензопила», «Клинок, рассекающий демонов», «Провожающая в последний путь Фрирен», «Дандадан» и другие известные сериалы. Одна франшиза встречается только один раз, даже если считать героев в теме персонаживотных. Всего с этой темой — 26 разных аниме-франшиз. Сезоны и альтернативные переводы не выдаются за разные сериалы.

Сложность создают детали знакомых миров, короткие опенинги, точные голосовые ответы и визуальные каламбуры. Основные ответы короткие; у персонаживотных принимается авторская склейка или обе верно названные части. «Кривые отзывы» написаны для пакета и не приписываются настоящим пользователям Steam.

Это переработанная редакция, а не полностью новый набор всех материалов: сохранены 14 удачных персонаживотных, часть знакомых голосов, музыки и скриншотов. Шесть новых иллюстраций используют героев GTA V, God of War, The Witcher 3, Doom, Minecraft и Resident Evil 4. Они сохранены как исходные PNG image_gen без редактирования. Другие сохранённые вопросы перераспределены; повторные аниме-франшизы исключены.

Все **50 картинок и 40 MP3** встроены в один `Bro-Pack-140-Remix.siq`. Игрокам нужен только SIGame и этот файл. [Как играть](HOW-TO-PLAY.txt). Ответы и источники в [pack.json](pack.json), [media-sources.json](media-sources.json) и [generation-prompts.json](generation-prompts.json) содержат спойлеры.

## Проверки

```bash
python sigame-packs/tools/validate_remix_content.py
python sigame-packs/tools/build_pack.py --pack sigame-packs/friends-remix --output dist/sigame-remix
python sigame-packs/tools/validate_pack.py dist/sigame-remix/Bro-Pack-140-Remix.siq --pack sigame-packs/friends-remix
dotnet run --project sigame-packs/tools/OfficialLoader --configuration Release -- dist/sigame-remix/Bro-Pack-140-Remix.siq dist/sigame-remix/build-info.json
```

Проверяются структура, официальная XML-схема, 140 вопросов, 28 тем, цены, ответы, все вложения и их хеши, полное декодирование картинок и звука, отсутствие повторных файлов, тишины, клиппинга и ответов в ID3. Дополнительная проверка считает аниме именно по франшизам, включая персонаживотных, проверяет ограничение Terraria и возраст игр по скриншотам. Импорт проверяет официальная SIPackages 7.14.0. Полная партия через графический клиент не заявлена как пройденная.

[Workflow сборки и релиза](../../.github/workflows/sigame-remix.yml). [Сборщик исходного содержания](../tools/compose_remix.py) принимает каталог просмотренных кадров, JSON выбранных кадров и исходники четырёх новых аудиофрагментов. Новые игровые скриншоты взяты из официальных галерей Steam; кадры аниме извлечены из оригинальных опенингов AnimeThemes. Короткие записи приведены к подходящей громкости. Полные видео и треки в пакет не включены. Материалы принадлежат авторам и правообладателям исходных произведений.
