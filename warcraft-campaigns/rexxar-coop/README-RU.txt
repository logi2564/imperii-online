Выгрузка исходных миссий Рексара для подготовки кооператива

Запрос: полная кампания «Основание Дуротара» для четырёх игроков, Warcraft III 1.26.
Сейчас нужен комплект оригинальных миссий из установленной игры. Кооперативная кампания ещё не собрана.

1. Скачай Export-Rexxar-Maps.exe и запусти обычным двойным щелчком.
2. Утилита попробует найти Warcraft. Если спросит папку — вставь путь к папке, где лежат War3x.mpq и War3Patch.mpq, и нажми Enter.
3. На рабочем столе появится папка Rexxar-sources-ДАТА. Пришли ZIP из этой папки и файл Rexxar-source-info.json в чат; можно положить всю папку в Google Drive и прислать ссылку.

Утилита читает только известные архивы Warcraft и ищет 17 карт: 5 для первого акта, 10 для второго и 2 для третьего. Архив обновления имеет приоритет; русские записи предпочтительны. Повреждённая запись проверяется через другие архивы.
Каждая миссия сохраняется побайтно. ZIP разбиваются по актам и при необходимости на части примерно до 24 МиБ, чтобы их было удобно передать.
Отчёт показывает найденные и отсутствующие миссии. Если найдены не все 17, это будет явно написано. В отчёт попадают имена архивов и карт, размеры и SHA-256; папка установки и посторонние файлы в него не включаются.
Программа работает с архивами игры в режиме чтения и создаёт результат в отдельной папке. Отправку файлов выполняешь ты.

Для запуска нужна Windows 10/11 x64. Отдельно устанавливать .NET не требуется. Утилита не запускает Warcraft или редактор.
Проверки экспорта выполняются на искусственных MPQ-архивах, включая запуск готового Windows EXE. Чтение именно твоей установки станет известно после запуска у тебя.

Для разработчика: исходники в tools/ExportRexxar. Чтение MPQ — War3Net.IO.Mpq 6.0.3. Команды --game ПАПКА --out ПАПКА --no-pause позволяют работать без вопросов в консоли. --self-test --no-pause запускает проверки в отдельной временной папке.
