РЕКСАР НА ЧЕТВЕРЫХ — ИСПРАВЛЕННЫЙ ВХОД, 17 МИССИЙ

Пользователь подтвердил открытие локального лобби карты C на Warcraft III
1.26.0.6401 после исправления конфликтов имён dialog/ability с типами Warcraft.
Это исправление внесено в общий код всех 17 карт. Первая карта в архиве
ПОБАЙТОВО совпадает с проверенной C; имя файла изменено на RX3-OrcX01.w3x
для совместимости переходов в главную область.

УСТАНОВКА И ПЕРВАЯ ИГРА
1. Распакуй ZIP в папку Warcraft III. Получится Maps\Rexxar-Coop-Fixed.
2. У всех игроков должны быть одинаковые карты из ЭТОГО архива.
3. Локальная сеть → Создать игру → Rexxar-Coop-Fixed → CHECK C - COOP FIX.
4. Игроки: красный — Рексар, фиолетовый — Рокхан, жёлтый — Чэнь,
   оранжевый — Кэрн. Остальные места принадлежат NPC/компьютеру.
5. Ведущий выбирает сложность. Начало — команда -start в чат.
Остальные области имеют подпись REXXAR FIX и имя OrcX01_02, OrcX02 и т. д.
Старые файлы RC1/RC2/RC3 находятся в других папках; используй новую папку.

IRINABOT
Загружай отдельные .w3x из Maps\Rexxar-Coop-Fixed как новые карты и выбирай
конфигурацию Warcraft 1.26. ZIP целиком не является картой для бота.
Прежняя страница №81743 хранит старый файл и сама не обновляется.
Подключение через IrinaBot здесь ещё не подтверждено; подтверждён локальный вход C.

СОХРАНЕНИЕ ПОСЛЕ МИССИИ
На завершении/переходе каждый получает ОДИН код. Повторить — -code.
Коды находятся и в F9 → «Код продолжения: герой 1/2/3/4»; все вместе —
F9 → «Сохранение отряда». Ведущий может показать все командой -codes.
Создайте указанную следующую карту новым сетевым лобби. До старта каждый
вводит -load СВОЙ_КОД. После приёма всех четырёх ведущий вводит -start.
Ведущий может ввести коды отсутствующих игроков; нужны все четыре кода,
поскольку они вместе хранят общий тайник и предметы временной спутницы Джайны.
Отдельные -party/-stash для новых кодов не требуются. Для очистки ошибочно
выбранных кодов до старта ведущий вводит -reset. Не смешивайте коды разных завершений.
Необязательная ручная запись — -save. Автоматическая выдача — в конце/на переходе.
RexxarCoop-Saves.exe лишь помогает скопировать команду из Logs; он не обязателен,
не запускает игру и не заменяет код из F9. Его можно оставить рядом с war3.exe.

ГЕРОИ И ПРАВИЛА
Четыре разных оригинальных героя, раздельные инвентари/навыки/ресурсы.
Дополнительная способность каждого — Z: Рексар призывает двух волков и лечит
отряд; Рокхан лечит/очищает; Чэнь создаёт шесть волн огня; Кэрн оглушает и лечится.
Сюжетный спутник заменяет временного героя своей роли с переносом развития.
Подкрепления и положительные награды делятся; герой возрождается через 15 секунд.
Баланс пока предварительный, полного прохождения четырьмя клиентами не было.

ЧТО ПОДТВЕРЖДЕНО
Пользователь открыл ЛОКАЛЬНОЕ ЛОББИ первой карты C на своём Warcraft 1.26a.
Первая карта в этом ZIP совпадает с ней байт в байт. Все 17 полных скриптов
проходят строгую проверку +shadow; структуры/типы объектов, ландшафт и ресурсы
проверены; исполняемые тесты проверяют код переноса вещей/опыта/навыков/тайника.
В архиве есть отчёт Fixed-package.json с хешами именно включённых файлов.
Это не подтверждение полного сетевого прохождения: все остальные лобби,
сцены/баланс и IrinaBot ещё не проверены в живом движке.
Переносятся герои/вещи/уровни/сюжет, а не полный снимок всех врагов и разрушений.
Между картами нужно новое сетевое лобби; бесшовный переход не реализован.
Повторное сохранение обычным World Editor перезапишет внедрённый JASS.
