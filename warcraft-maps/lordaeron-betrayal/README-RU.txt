Lordaeron Wars / Betrayal 1.22 — NewGen FIX2 для Warcraft III 1.26

СКАЧИВАНИЕ И ИГРА
Скачай Lordaeron-Wars-1.22-NewGen-FIX2.w3x из раздела Assets релиза.
Для игры положи файл в Warcraft III\Maps\Download.
Всем игрокам нужна одна и та же версия карты.
Файл занимает 8 334 699 байт (7,95 МиБ): меньше лимита 8 МиБ старого Warcraft.
Архив использует классический MPQ v0, обычные секторы 32 КиБ и DEFLATE; содержимое ресурсов сжато без потерь.
Исходный игровой скрипт сохранён побайтно. Игра в настоящем клиенте 1.26 здесь не запускалась.

РЕДАКТИРОВАНИЕ НА 1.26
Новая версия Warcraft не требуется. Размер исходной карты — 192×288 клеток.
Обычный World Editor 1.26 ограничен размером 256×256: для такой карты нужен Jass NewGen Pack (JNGP), совместимый с Warcraft III 1.26.
В редакторе JNGP: «Файл → Открыть» → выбери .w3x. Сохраняй под новым именем.
Проверку открытия/сохранения в настоящем Windows World Editor/JNGP здесь выполнить нельзя.
После сохранения старым редактором карта может снова стать больше 8 МиБ из-за повторной записи ресурсов.

ИСПРАВЛЕНИЕ FIX2
Предыдущая версия не открывалась с ошибкой «Сведения об уровнях отсутствуют или неверны».
Причина: режим хранения SINGLE_UNIT не поддерживается для карт Warcraft III. Два общих MPQ-парсера принимали его, но загрузчик Warcraft игнорировал этот флаг и не мог прочитать файлы.
В FIX2 файлы записаны обычными секторами. Полная карта с заголовком HM3W проверена через нативную StormLib: прочитаны все 443 записи, контрольные суммы совпадают. Отдельная регрессионная проверка воспроизводит отказ старой упаковки с ошибкой 1004.
Настройки NewGen/UMSWE 5.0 из-за этой ошибки менять не требуется; «Enable No Limits» для размера карты должен оставаться включённым.
Само окно NewGenWE/JNGP на Windows в этой среде не запускалось.

ЧТО ВОССТАНОВЛЕНО
Удалены пропуск данных редактора и некорректный заголовок MPQ из предыдущей сборки.
Восстановлены размещение 1962 юнитов и 11 стартовых позиций, 180 областей, 85 звуковых/музыкальных записей, 6 таблиц предметов, настройки улучшений и дерева технологий.
В редакторе триггеров (F4) нажми на название карты вверху дерева: там восстановленный JASS-код.
Исходное дерево GUI-триггеров было удалено; вместо него восстановлен код 966 функций.
Триггер Recovery подключает восстановленную логику. EditorReferences не имеет событий и сам не выполняется: не удаляй его, он сохраняет ссылки на юнитов и разрушаемые объекты при генерации скрипта.
Изменения рельефа, объектов и размещения доступны в редакторе.

РЕСУРСЫ И ПРОВЕРКИ
Все 385 исходных игровых файлов сохранены с совпадением SHA-256; изменены служебные данные редактора и добавлены восстановленные файлы.
Для 48 ресурсов исходные имена неизвестны: оригинальные записи сохранены, копии доступны в импортах под RecoveredUnknown\<хеш>. После пересохранения ссылки на первоначальные неизвестные имена могут потребовать ручного восстановления.
51 повторяющаяся запись теперь использует общий блок архива; файлы и их содержимое сохранены.
Файлы проверены общими MPQ-парсерами и нативной StormLib в режиме карты Warcraft III; игровой скрипт и моделируемый скрипт пересохранения прошли pjass со старым набором common.j/Blizzard.j без ошибок. Это проверка структуры и кода, а не полноценная игровая партия.
Подробный отчёт: verification.json. Контрольная сумма: SHA256SUMS.txt.
