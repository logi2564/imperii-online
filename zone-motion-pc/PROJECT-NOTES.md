# Zone Motion — проект переноса на Windows

**Это восстановленный Unity-проект, готового Windows EXE в этом релизе нет.** Запуск и игровой процесс на Windows ещё не проверены.

Скачайте **ZoneMotion-PC-project.zip**, распакуйте и дважды нажмите **ИГРАТЬ.cmd**. Если готовой сборки ещё нет, скрипт вызывает установленный и активированный **Unity Editor 2017.2.0f3** с Windows x64 Build Support. После успешной сборки он запускает игру. Если Unity не установлен или сборка не удалась, показывает причину и оставляет окно открытым. Скрипт не устанавливает и не активирует Unity автоматически.

Ручной способ: откройте папку **project** в редакторе и выберите **Tools → Zone Motion → Build Windows x64**. Результат: **dist/ZoneMotionPC/ZoneMotionPC.exe** вместе с папкой данных. Редактор нужен только для сборки; игрокам он не требуется.

Восстановлены меню и 13 локаций. Добавлены масштаб колесом мыши, перетаскивание карты правой/средней кнопкой, камера на WASD, возврат к персонажу на F и пауза/управление на Esc/F1. Для Windows подготовлен автономный вариант Google Play; Android-реклама недоступна и награды за непросмотренную рекламу не выдаются.

Локально проверены компиляция всех 795 игровых C#-файлов для настольных и Android-условий (0 ошибок), порядок 14 сцен и ссылки ресурсов. CI проверяет соответствие файлов этому проверенному снимку, структуру архива и его CRC. Эти проверки не заменяют сборку Unity Player и проверку игры на Windows. Подробности — **README-PC.md** и **VALIDATION.json** в архиве.

Игра: **Zone Motion 1.275**, автор **Sokol**. Восстановление выполнено из предоставленного APK; подготовленные изменения предназначены для переноса на ПК.
