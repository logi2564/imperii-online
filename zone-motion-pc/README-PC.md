# Zone Motion — перенос на Windows

Подготовлен восстановленный Unity-проект игры **Zone Motion 1.275**, автор **Sokol**. Это рабочие файлы переноса: готовый Windows EXE пока не собран, запуск и игровой процесс на Windows ещё не проверены.

## Что подготовлено

- Меню и все 13 локаций, исходный порядок загрузки сцен и ресурсы игры.
- Восстановленная C#-логика. Исходная сборка и настольные изменения проверяются компилятором против библиотек Unity 2017.
- Управление картой: выбор левой кнопкой мыши, перетаскивание правой или средней кнопкой, камера на WASD, масштаб колесом, возврат к персонажу на F.
- Пауза и подсказка управления на Esc/F1. Во время паузы блокируются нажатия на игровой интерфейс; после закрытия восстанавливается прежняя скорость игры.
- Google Play использует предусмотренный SDK автономный клиент на Windows. Android-реклама на ПК недоступна; дополнительные награды за непросмотренную рекламу не выдаются.
- Начальное окно 1280×720 без диалога разрешения и с одним экземпляром игры. Изменение размера окна отключено, поскольку исходный интерфейс рассчитывает размеры при загрузке сцены.

Персонажи, задания, бой и локальная система сохранений сохранены в восстановленной игровой логике. Полную работоспособность нужно подтвердить запуском игры, а не одной компиляцией скриптов.

## Получение Windows-сборки

Нужен **активированный Unity Editor 2017.2.0f3** с компонентом **Windows x64 Build Support**. Лицензия Unity и редактор не входят в эти файлы. Подходящая страница официальных версий: https://unity.com/releases/editor/archive.

1. Откройте папку `project` в Unity. Дождитесь импорта файлов и проверьте Console: ошибок компиляции быть не должно.
2. Выберите **Tools → Zone Motion → Build Windows x64**. Либо на Windows запустите `BUILD-WINDOWS.cmd`; для нестандартного расположения редактора задайте `UNITY_EDITOR_PATH`.
3. Результат появится в `dist/ZoneMotionPC`. Запускается `ZoneMotionPC.exe`; папка данных рядом с ним тоже необходима. Сборка одного переносимого EXE возможна после проверки этой папки на Windows.

Переход на другую версию Unity требует дополнительной проверки UI-библиотек, ресурсов, API и сохранений. Восстановленные материалы включают сгенерированные AssetRipper шейдеры; внешний вид необходимо сравнить с Android-версией.

## Проверка настоящей сборки

Перед выдачей готовой версии нужно проверить меню и новую игру, вход на Кордон, выбор клетки и движение персонажа, перетаскивание и масштаб карты, горячие клавиши, паузу с блокировкой кликов, локальное сохранение и загрузку после перезапуска. Затем проверить переход между локациями и ошибки в журнале Unity Player.
