# Zone Motion — Windows-сборка и исходный проект

**Готовая первая сборка:** [ZoneMotion-PC-Windows.exe](https://github.com/logi2564/imperii-online/releases/download/zone-motion-pc-v0.1-e022175d/ZoneMotion-PC-Windows.exe). Это один переносимый EXE игры **Zone Motion 1.275**, оригинальный автор **Sokol**. Для запуска устанавливать Unity, Codex или эмулятор не нужно.

Именно опубликованный переносимый EXE запускался на Windows в GitHub Actions: проверены меню, новая игра на Кордоне с 17 персонажами, сохранение и повторная загрузка без игровых исключений. Кадры игры также проверены. Проверка выполнена программным Vulkan-рендерером; вся кампания и все варианты оборудования ещё не проверены.

Инструменты в `native/` готовят пакет из исходного APK и официального Windows runtime Unity 2017.2.0f3, адаптируют формат игровых данных, объединяют Android split-файлы, преобразуют мобильные текстуры и компилируют настольный C#-код. Движок и графические DLL копируются без модификации; лицензионные поля и заставка Unity сохранены. Запуск выбирает доступное устройство Vulkan или встроенный программный рендерер. Упаковщик NSIS собирает компоненты в один временно распаковываемый EXE.

Папка `project` содержит отдельно восстановленный Unity-проект. `VALIDATION.json` относится к его статической компиляции и ссылкам ресурсов; импорт и сборка именно этого проекта в Unity Editor по-прежнему не проверены. Ниже описан дополнительный путь разработки через редактор. Для обычной игры используйте готовый EXE по ссылке выше.

## Что подготовлено

- Меню и все 13 локаций, исходный порядок загрузки сцен и ресурсы игры.
- Восстановленная C#-логика. Исходная сборка и настольные изменения проверяются компилятором против библиотек Unity 2017.
- Управление картой: выбор левой кнопкой мыши, перетаскивание правой или средней кнопкой, камера на WASD, масштаб колесом, возврат к персонажу на F.
- Пауза и подсказка управления на Esc/F1. Во время паузы блокируются нажатия на игровой интерфейс; после закрытия восстанавливается прежняя скорость игры.
- Google Play использует предусмотренный SDK автономный клиент на Windows. Android-реклама на ПК недоступна; дополнительные награды за непросмотренную рекламу не выдаются.
- Начальное окно 1280×720 без диалога разрешения и с одним экземпляром игры. Изменение размера окна отключено, поскольку исходный интерфейс рассчитывает размеры при загрузке сцены.

Персонажи, задания, бой и локальная система сохранений сохранены в восстановленной игровой логике. Полную работоспособность нужно подтвердить запуском игры, а не одной компиляцией скриптов.

## Дополнительная сборка восстановленного проекта через Unity Editor

Нужен **активированный Unity Editor 2017.2.0f3** с компонентом **Windows x64 Build Support**. Лицензия Unity и редактор не входят в эти файлы. Подходящая страница официальных версий: https://unity.com/releases/editor/archive.

**`ИГРАТЬ.cmd` — помощник сборки для разработчика.** Он вызывает установленный Unity, собирает восстановленный проект и запускает полученный EXE. Если Unity не установлен или сборка не удалась, окно показывает причину. Готовая переносимая игра по ссылке выше использует отдельный процесс подготовки `native/` и в этом скрипте не нуждается.

Редактор должен быть закрыт перед сборкой из CMD. Для нестандартного расположения укажите полный путь к `Editor\Unity.exe` в переменной `UNITY_EDITOR_PATH`. Сборка через меню редактора остаётся доступна:

1. Откройте папку `project` в Unity. Дождитесь импорта файлов и проверьте Console: ошибок компиляции быть не должно.
2. Выберите **Tools → Zone Motion → Build Windows x64**. Либо на Windows запустите `BUILD-WINDOWS.cmd`; для нестандартного расположения редактора задайте `UNITY_EDITOR_PATH`.
3. Результат появится в `dist/ZoneMotionPC`. Запускается `ZoneMotionPC.exe`; папка данных рядом с ним тоже необходима. После этого можно пользоваться `ИГРАТЬ.cmd` или передать друзьям всю папку `dist/ZoneMotionPC`: для её запуска Unity им не нужен.

Переход на другую версию Unity требует дополнительной проверки UI-библиотек, ресурсов, API и сохранений. Восстановленные материалы включают сгенерированные AssetRipper шейдеры; внешний вид необходимо сравнить с Android-версией.

## Проверка настоящей сборки

Перед выдачей готовой версии нужно проверить меню и новую игру, вход на Кордон, выбор клетки и движение персонажа, перетаскивание и масштаб карты, горячие клавиши, паузу с блокировкой кликов, локальное сохранение и загрузку после перезапуска. Затем проверить переход между локациями и ошибки в журнале Unity Player.
